مجموعه‌ای فارسی و راست‌به‌چپ برای ساخت ویدیوی موشن با **ایجنت آراِنا** و **Remotion** — بدون نوشتن کد.

| [`کاتالوگ-۳۰-سبک.html`](کاتالوگ-۳۰-سبک.html) | ۳۰ سبک گرافیکی با تصویر، دسته‌بندی، سختی و پرامپت |

| [`منابع-کلیپ‌ها.md`](منابع-کلیپ‌ها.md) | منبع و مجوز کلیپ نمونه‌ی هر سبک (Pexels) + روش جایگزینی با رندر خودمان |

## اجرا

فایل‌های HTML کاملاً خودکفا هستند (فونت وزیرمتن و تصاویر به‌صورت base64 جاسازی شده‌اند)؛
کافی است `index.html` را در مرورگر باز کنید — بدون سرور و بدون اینترنت.

```bash
# موتور ویدیو
cd motion-starter
npm install
npx remotion studio        # پیش‌نمایش
npx remotion render <id> out/<id>.mp4
```

## مجوز یادآوری

Remotion برای تیم‌های تا ۳ نفر رایگان است؛ برای بیشتر از آن نیاز به لایسنس تجاری دارد.

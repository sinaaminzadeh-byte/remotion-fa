# استودیوی موشن — موشن‌گرافیک فارسی با Remotion

مجموعه‌ای فارسی و راست‌به‌چپ برای ساخت ویدیوی موشن با **ایجنت آراِنا** و **Remotion** — بدون نوشتن کد.

تهیه شده توسط **سینا امین‌زاده** · اینستاگرام و تلگرام: `@ai_sinaaminzadeh`

## فایل‌ها

| فایل | توضیح |
|---|---|
| `index.html` | صفحهٔ خانه |
| `آموزش-ساخت-موشن.html` | راهنمای گام‌به‌گام ساخت ویدیو با ایجنت + بخش ۳۹ سبک کدی |
| `کاتالوگ-۳۰-سبک.html` | ۳۰ زبان بصری با کلیپ/تصویر، دسته‌بندی و پرامپت |
| `۳۹-سبک-کدی.html` | ۳۹ سبک آمادهٔ رندر با کد + کلیپ واقعی هر سبک |
| `previews/` | ۱۳ رندر نهایی خودمان (MP4) + فریم‌های ساکن |
| `motion-starter/` | پروژهٔ Remotion که این ۱۳ سبک را می‌سازد |
| `animation-styles/` | پروژهٔ ۳۹ سبک کدی (Remotion) |

## اجرا

فایل‌های HTML خودکفا هستند (فونت وزیرمتن و رسانه‌ها base64) — فقط `index.html` را باز کن.

```bash
cd motion-starter && npm install
npx remotion render <CompositionId> out/<name>.mp4
```
